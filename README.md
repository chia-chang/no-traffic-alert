# no-traffic-alert
Only counts days after each provider's go-live date.

50d = <Date Start _ 50> ~ <Report Day>            This week = <Date Start _ 7> ~ <Report Day>
Total wager (50d) = total wager in the 50d window.
Potential wager = each stopped provider's average daily wager (50d, days with traffic only) × its days with no traffic this week, summed per casino.
